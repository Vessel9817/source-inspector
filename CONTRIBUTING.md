# Contributing Guidelines

We welcome issues or pull requests. Before opening an issue, we ask that you
first briefly look through the [open issues][issues] for any duplicate
or related issues.

For a shortlist of features we're considering, see the [TODOs](TODO.md).

## Areas where we're always in need of contributors

- [Translation](_locales)
- Legal
- Following W3C standards, WHATWG standards and the HTML Living Standard
